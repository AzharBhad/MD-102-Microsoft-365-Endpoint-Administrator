## How to use them

1. Do a domain's questions **after** its docs and labs, without looking at the answers.
2. For each miss, read the answer explanation, then the **Exam tips and common traps** section of the objective's doc.
3. Take the mock exam in week 8 under time pressure. Aim for **40/50 or more**.
4. Record scores in [PROGRESS-TRACKER.md](../PROGRESS-TRACKER.md#practice).

## Format

Each question has a `### Q<domain>.<number>` heading (mock: `### QM.<number>`), options A-D (sometimes "select two"), an `**Objective:**` line, and the answer with a short explanation inside a collapsible block. Contributions must follow the same format and be original - see [CONTRIBUTING.md](../CONTRIBUTING.md).
