# 8-week study plan

About **9 hours per week** (for example, 1 hour on weekdays + 4 hours at the weekend for labs). Weeks follow Microsoft's domain order and give Domain 2 - the heaviest - two weeks. Tick items off in [PROGRESS-TRACKER.md](../PROGRESS-TRACKER.md).

> **Retaking in 2-3 months?** Use weeks 1-6 for your weakest domains first (from your score report and the Learn practice assessment), then keep weeks 7-8 as written.

| Day | Task |
|---|---|
| 1 | Take the Microsoft Learn **practice assessment** cold. Save the score. Read the [roadmap](study-roadmap.md) |
| 2 | [Licensing guide](licensing-guide.md) + [cheat sheet](../07-Cheat-Sheets/08-licensing-minimums.md) |
| 3-4 | Build the [lab environment](lab-environment-setup.md): trial tenant, users/groups script, 2 Hyper-V VMs |
| 5 | Docs 1.1.1-1.1.4 (join types, groups) |

| Day | Task |
|---|---|

| 3 | All [cheat sheets](../07-Cheat-Sheets/README.md), [glossary](../GLOSSARY.md), [troubleshooting flows](../09-Troubleshooting/troubleshooting-flows.md) |
